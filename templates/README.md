# 模板目录

把要参考的模板放这里，支持 `.md / .csv / .xlsx / .docx`。

## 用途

- **用例/测试点模板** → 会合并进 `skills/cts-case-authoring.md` 与 `skills/cts-test-design.md` 的字段与写法要求
- **质量检查表** → 会转成 `lint()` 的检查项
- **字段定义（列名/取值）** → 会进入导出列映射与 rubric 评分

## 命名建议

| 前缀 | 含义 |
|---|---|
| `case-` | 用例模板 |
| `point-` | 测试点模板 |
| `lint-` | 检查项/规范 |
| `field-` | 字段与列定义 |

放入后告诉我文件名，我会逐个对照现有 skill 与导出格式，列出差异并合并。
